# Documentação do Projeto Rhyme

Este repositório contém a documentação técnica e de engenharia de software do projeto **Rhyme** (PWA de rastreamento em tempo real do transporte universitário intermunicipal).

A documentação da disciplina **INF0449 — Processos de Engenharia de Software (UFG 2026/2)** foi elaborada com base na norma internacional **ISO/IEC/IEEE 12207:2017**.
